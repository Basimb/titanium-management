# فريق إدارة تيتانيوم

نظام داخلي مبسّط لمتابعة المشاريع والمهام والمسؤولين والملاحظات والموافقات.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## الإنتاج

```bash
npm run build
npm start
```

يتطلب Node.js 22. تُحفظ البيانات والملفات المرفوعة محليًا داخل مجلد `data/`، وهو مستثنى من Git.

## الأمان

- لا تُرفع ملفات `.env` أو قاعدة البيانات إلى المستودع.
- يحدد باسم كود المدير عند التشغيل الأول.
- يضيف المدير أكواد بقية أعضاء الفريق من داخل النظام.
